   - https://netlas.io/                    : IP, domain, and certificate mapping engine.
   - https://www.favihash.com/             : Identify Origin web servers via Favicon MD5/Murmur3 hash.

3. Historical Web Archives & Threat Intel:
   - https://web.archive.org/cdx/search/cdx: Query Wayback Machine index for endpoints & JS.
   - https://urlscan.io/                   : Web page scan archive, outbound HTTP calls, DOM dumps.
   - https://otx.alienvault.com/           : AlienVault Open Threat Exchange domain telemetry.
   - https://www.virustotal.com/           : Passive DNS resolution and threat reputation.

SECTION 01: PASSIVE SUBDOMAIN ENUMERATION
================================================================================
Gather subdomains from public third-party archives without sending packets to target:

1. subfinder:
   subfinder -d example.com -o Subs01.txt
   subfinder -d example.com -all -recursive -o Subs01.txt
   subfinder -dL targets.txt -all -recursive -o subs_all.txt

2. assetfinder:
   echo example.com | assetfinder -subs-only > Subs02.txt
   cat targets.txt | assetfinder -subs-only >> Subs02.txt

3. amass:
   amass enum -passive -d example.com -o Subs03.txt
   amass enum -d example.com -brute -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-110000.txt -o Subs03_brute.txt

4. subenum:
   ./subenum.sh -d example.com -u wayback,crt,abuseipdb,Findomain,Subfinder,Amass,Assetfinder -o Subs04.txt
   ./subenum.sh -l targets.txt -u wayback,crt,abuseipdb,Findomain,Subfinder,Amass,Assetfinder -o Subs04.txt

5. findomain:
   findomain -t example.com -u Subs05.txt
   findomain -f targets.txt -u Subs05.txt

6. chaos (ProjectDiscovery Cloud):
   export PDCP_API_KEY="your_api_key_here"
   chaos -d example.com -o Subs06.txt

7. github-subdomains:
   github-subdomains -d example.com -t YOUR_GITHUB_TOKEN -o Subs_gh.txt

8. Certificate Transparency (crt.sh API):
   curl -s "https://crt.sh/?q=%25.example.com&output=json" \
     | jq -r '.[].name_value' \
     | sed 's/\*\.//g' \
     | tr '\n' ',' | tr ',' '\n' \
     | grep -oE "[A-Za-z0-9._-]+\.example\.com" \
     | sort -u > Subs_crt.txt

================================================================================
Actively probe DNS nameservers using massive brute-force wordlists:

1. dnscan:

SECTION 05: INFRASTRUCTURE DISCOVERY (ASN, CIDR, REVERSE DNS)
================================================================================
Identify the organization's autonomous systems, IP blocks, and reverse DNS:

1. asnmap (Map organization ASN to IP prefixes):
   asnmap -a AS17012 -silent
   asnmap -org "Target Org" -silent -o cidrs.txt

2. whois (RADB / BGP routing queries):
   whois -h whois.radb.net -- '-i origin AS17012' | grep -Eo "([0-9.]+){4}/[0-9]+" | sort -u > cidrs.txt

3. hakrevdns (Reverse DNS over IP ranges):
   cat cidrs.txt | mapcidr -silent | hakrevdns -r 1.1.1.1 -o revdns_subs.txt
   echo "192.168.1.0/24" | hakrevdns -r 1.1.1.1
   hakrevdns -d example.com -R resolvers.txt

4. mapcidr (CIDR expansion and aggregation):
   cat cidrs.txt | mapcidr -silent > ips.txt
   mapcidr -cidr 192.168.0.0/16 -silent

Extract API keys, tokens, hardcoded routes, and DOM sinks from client-side JS:

1. subjs:
   cat AllURLs.txt | subjs | sort -u > js_files.txt

   grep -E "api[_-]?key|token|secret|password|bearer|auth|aws|s3" script.js
