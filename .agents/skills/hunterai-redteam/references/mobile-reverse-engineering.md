# Mobile and reverse engineering

Record hashes, package identifiers, versions, signatures, architectures, frameworks, and build type for APK/XAPK/AAB/IPA and native artifacts. Inspect manifests, entitlements, components, deep links, permissions, WebViews, storage, backups, logs, cryptography, network policy, updates, and embedded endpoints.

Decompile or disassemble Java/Kotlin, Swift/Objective-C, ELF/Mach-O, Flutter AOT, React Native/Hermes, Unity/IL2CPP, and custom bytecode as applicable. Trace network builders, authentication, serialization, signing, encryption, device state, storage, and response handling.

Use the supplied device or emulator for installation, UI exercise, proxy capture, logs, storage, method hooks, and native instrumentation. When pinning, integrity, anti-debug, root/jailbreak, emulator, or instrumentation checks block requested analysis, locate the enforcement point and apply the minimum requested patch or hook while preserving the original artifact and recording the transformation.

Keep complete cookies, tokens, authorization values, device identifiers, headers, bodies, encodings, and protocol fields for replay. Distinguish decompiler output, runtime observation, inference, and verified server behavior.
