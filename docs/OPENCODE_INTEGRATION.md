## 3. Offensive MCP servers — MANUAL GATE (do not guess)

Per repo rules, offensive MCP servers are **never** pre-configured. To enable one:
1. Valid `AUTHORIZATION.txt` covering the target scope is on file,
2. Read that repo's README for the exact run command (never assume ports/commands),
3. Add to `opencode.json` only after verification, `enabled:false` → flip per engagement,
4. Kill any server after 10-minute failed install.

## 5. Update procedure

Everything (deps + packs + skills + validation) lives in one file:

```powershell
.\install_agent.ps1                  # full install / refresh (idempotent)
.\install_agent.ps1 -Profiles core,redteam
.\install_agent.ps1 -Full            # install ALL skills in library
.\install_agent.ps1 -CheckOnly       # environment validation only
.\install_agent.ps1 -KaliTools       # + Kali arsenal via WSL
```

Manual pack refresh (alternative):

```bash
# refresh packs
git -C skills_library/anthropic-cyber pull --ff-only
git -C skills_library/trailofbits pull --ff-only
git -C skills_library/briiirussell pull --ff-only
git -C skills_library/anthropics pull --ff-only
git -C skills_library/microsoft pull --ff-only

# re-run installer (dedupes, rewrites frontmatter, refreshes MANIFEST)
python tools/install_opencode_skills.py --clean --profiles core
```
